# 🗂️ Catalog & Manifest Index (`catalog/`)

Structured JSON manifests organizing all 2D images, 3D Blender models, and animations in this repository:

| Manifest File | Description |
| :--- | :--- |
| [`by_character.json`](by_character.json) | All **318 high-resolution 2D images** grouped by character (19 categories, including 107 CatNap & 105 Baba Chops assets) |
| [`models_and_animations.json`](models_and_animations.json) | Complete metadata for the **Baba Chops 3D Base Model** (`.blend`, `.glb`, `.obj`, `.py`) and **6 Baked NLA Animations** (featuring `Baba_Fart_Blast`) |
| [`../catalog.json`](../catalog.json) | Flat 318-item root manifest preserved for backward compatibility with existing web apps |
